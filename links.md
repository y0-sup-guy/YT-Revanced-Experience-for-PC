# Downloads and extension links

These are the official project and Chrome Web Store pages for the apps and extensions shown in the setup screenshots. Store pages, versions, and availability can change, so check the listing before installing anything.

## Required for routing

| Component | Link | What it is for |
|---|---|---|
| LinkRouter for Windows | [Official releases](https://github.com/kolbasky/LinkRouter/releases/latest) | Routes links using the rules in the configuration. |
| LinkRouter Chromium browser companion | [Official releases](https://github.com/kolbasky/LinkRouter/releases/latest) | Lets the browser send links to LinkRouter. Get the Chromium extension from the official release or installer instructions. |
| LinkRouter PWA Cross-Domain Handoff | Download link will be added to this repository's **Releases** page. | Used by the Studio, activation, and Music handoff rules. |
| Google Chrome | [Official download](https://www.google.com/chrome/) | Browser used by this template. |
| YouTube | [youtube.com](https://www.youtube.com/) | Website installed as a PWA. |
| YouTube Music | [music.youtube.com](https://music.youtube.com/) | Destination handled by a configured rule. |
| YouTube Studio | [studio.youtube.com](https://studio.youtube.com/) | Destination handled by a configured rule. |

## Optional Chrome Web Store extensions

These extensions are in the reference setup but are **not required** for LinkRouter routing. Install only the ones you want, and read the permissions and privacy disclosures on their official pages.
