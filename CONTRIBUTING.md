# Contributing

Corrections to the setup instructions, verified links, and tested routing rules are welcome.

Before submitting changes:

1. Do not include account details, activation codes, cookies, tokens, or personal app IDs/profile names.
2. Keep `config/linkrouter-template.json` generic. Do not replace the placeholders with values from your own computer.
3. Preserve the order of specific rules before generic rules.
4. Run `py .\scripts\validate-config.py` after editing JSON.
5. State which routes you tested and the Windows, Chrome, and LinkRouter versions used.
6. Do not add third-party extension source or installers unless redistribution is permitted; link to the official listings instead.
7. Keep the README clear about known limitations and browser-specific requirements.
